# Artiste Dz (آرتيست ديزاد)

> **الموقع الرسمي لمنصة Artiste Dz الإعلامية بقيادة الإعلامي والناقد السينمائي حليم زروقي**  
> *Official Media Portfolio & Digital Journal for Artiste Dz, led by film journalist, critic, and celebrity interviewer Halim Zerrouki.*

---

## 🌟 Overview / نظرة عامة
**Artiste Dz** is a premier Algerian digital media outlet dedicated to cinema, arts, music, and red-carpet entertainment journalism. Founded and directed by **Halim Zerrouki**, the platform serves as an exclusive cultural bridge connecting Algerian cinema icons, Arab stars, and urban music pioneers with audiences across North Africa and the Arab world.

---

## 🎨 Theme & Design System
- **Brand Colors**: Red & White (`#e50914`, `#ffffff`, `#faf9f6`)
- **Typography & Aesthetics**: Inspired by the prestigious **AncoraThemes Writer (Home 4)** editorial magazine style:
  - High-contrast pure black typography (`#000000`) on clean canvas
  - Centered editorial titles with symmetrical crimson dash accents (`::before` / `::after`)
  - Display Serifs: *Frank Ruhl Libre* & *Amiri*
  - Modern Sans: *Cabinet Grotesk*, *Inter*, & *Tajawal*
- **Multilingual & Bi-directional**: Full RTL (العربية) and LTR (Français, English) support.
- **100% Responsive**: Optimized across mobile phones, tablets, and high-DPI desktop viewports.

## 🚀 Running Locally
You can run this project with any local HTTP server:

```bash
# Python 3
python3 -m http.server 8080

# Or with Node.js
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
